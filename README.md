# 📄 Mi CV Profesional

Plantilla de curriculum vitae moderno, responsive y editable. Incluye visor de PDF integrado en modal.

## 🚀 Demo
Puedes verlo en: `https://TU-USUARIO.github.io/TU-REPO/`

## 📁 Estructura
- `index.html` — Estructura del CV
- `css/styles.css` — Estilos modernos
- `js/script.js` — Lógica del visor PDF y datos editables
- `assets/img/` — Foto de perfil
- `assets/pdf/` — Documentos PDF

## ✏️ Cómo editar
1. Abre `js/script.js` y edita el objeto `DATOS` con tu información.
2. Reemplaza `assets/img/foto-perfil.jpg` con tu foto.
3. Coloca tus PDFs en `assets/pdf/` y actualiza los `data-pdf` en `index.html`.

## 🖨️ Imprimir / Guardar como PDF
Haz clic en el botón flotante azul (arriba a la derecha) para imprimir tu CV desde el navegador.
